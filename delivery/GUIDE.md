## 1. Что это такое

**Voice Studio MVP** — это веб-сервис для разделения аудио на **вокал** и **инструментал**, автоматической транскрипции текста и записи каверов прямо в браузере телефона.

Всё работает локально на твоём телефоне (Android + Termux). Тяжёлые вычисления (нейросети) выполняются на бесплатном Google Colab с GPU.

**Что умеет система:**
- Загрузить MP3/WAV/FLAC/M4A
- Разделить на вокал и инструментал (Demucs)
- Транскрибировать текст с таймингами (Whisper)
- Нарезать фразы для карaoke
- Karaoke-плеер с подсветкой строк в браузере
- Редактировать LRC-текст с undo/redo
- Записать свой голос поверх инструментала
- Экспортировать в LRC / SRT / VTT / MIDI
- PWA — устанавливается на рабочий стол телефона

## 2. Как устроена система

```
Телефон (Termux)                     Google Colab
─────────────────────                ─────────────────────
FastAPI сервер  ←──────── HTTPS ────→  Colab Worker
SQLite база                            │
storage/ (файлы)                       ├─ Demucs (разделение)
localhost:8000                         └─ Whisper (транскрипция)
      ↕
Браузер телефона
(UI на Jinja2 + JS)
```

1. **Ты** загружаешь трек через браузер на телефоне
2. **FastAPI** сохраняет файл и создаёт задачу в SQLite
3. **Colab** каждые 10 секунд спрашивает: «Есть работа?»
4. **Colab** скачивает трек, запускает Demucs + Whisper, отправляет результаты обратно
5. **FastAPI** сохраняет вокал/инструментал/LRC и нарезает фразы
6. **Ты** открываешь karaoke-плеер в браузере

## 3. Установка на телефон (Termux)

### 3.1 Установи Termux

Скачай с F-Droid (не из Google Play — там устаревшая версия):
https://f-droid.org/packages/com.termux/

### 3.2 Обновление и базовые пакеты

```bash
pkg update && pkg upgrade -y
pkg install python ffmpeg nodejs git -y
```

### 3.3 Распакуй архив

```bash
# Скопируй voice_studio_mvp_full.zip на телефон
# Например через ADB, Telegram, или Google Drive

mkdir -p ~/voice_studio
cd ~/voice_studio
unzip /sdcard/Download/voice_studio_mvp_full.zip
cd clean/
```

### 3.4 Установи Python-зависимости

```bash
pip install -r requirements.txt
```

Установка займёт 2–5 минут. Если есть ошибки с `aiosqlite` — попробуй:

```bash
pip install aiosqlite --break-system-packages
```

### 3.5 Установи localtunnel

```bash
npm install -g localtunnel
```

## 6. Настройка Colab-воркера

### 6.1 Открой ноутбук

В архиве есть файл `colab_worker.ipynb`. Загрузи его на Google Drive и открой в Colab.

Или создай новый ноутбук и скопируй ячейки вручную.

### 6.2 Включи GPU

В Colab: **Runtime → Change runtime type → T4 GPU**

Без GPU Demucs будет работать в 10–20 раз медленнее.

### 6.3 Заполни конфиг (ячейка 1)

```python
STUDIO_URL    = "https://voice-studio-XXXXX.loca.lt"  # из start.sh
COLAB_SECRET  = "мой_секрет_123"                      # из .env

DEMUCS_MODEL  = "htdemucs"    # рекомендуется для начала
WHISPER_MODEL = "base"        # tiny/base/small/medium/large
```

### 6.4 Запусти все ячейки

**Runtime → Run all**

Воркер запустится и начнёт опрашивать сервер каждые 10 секунд.

### Что делает Colab-воркер

| Шаг | Действие |
|-----|---------|
| 1 | Спрашивает `GET /api/jobs/pending` |
| 2 | Берёт задание `POST /api/jobs/{id}/claim` |
| 3 | Скачивает оригинальный WAV с телефона |
| 4 | Запускает Demucs → vocal.wav + instrumental.wav |
| 5 | Отправляет файлы обратно `POST /api/jobs/{id}/complete` |
| 6 | Берёт задание транскрипции |
| 7 | Запускает Whisper → сегменты с таймингами |
| 8 | Отправляет сегменты `POST /api/jobs/{id}/complete-transcription` |
| 9 | Сервер нарезает фразы на телефоне (FFmpeg) |

### 7.6 Студия записи `/projects/{id}/record`

Страница состоит из **трёх шагов**.

#### Шаг 1: Измерение задержки

```
1 Latency    2 Запись    3 Превью
────────────────────────────────────────────────────
Измерение задержки
Включи звук и нажми кнопку. Займёт ~3 секунды.

[🎤 Измерить задержку]   [Пропустить (offset = 0)]

┌─────────────────────────────┐
│  86 мс                      │ ← результат
│ миллисекунд                 │
│ Round-trip: 172 мс          │
│ Замеры: 168, 170, 178 мс    │
│ Точность: 91%               │
└─────────────────────────────┘

Ручная корректировка: [────●────────] 86 мс

                              [Перейти к записи →]
```

**Зачем нужно измерение?** На разных телефонах задержка между воспроизведением и записью отличается (50–300мс). Без коррекции голос в миксе будет смещён.

**Как работает измерение:**
1. Система воспроизводит короткий chirp через динамик
2. Микрофон его улавливает
3. Вычисляется время от воспроизведения до улавливания
4. Результат / 2 = задержка в одну сторону

**Ручная корректировка:** ползунок от -200 до +500мс. Положительное значение → голос задерживается в миксе. Если автоизмерение дало странный результат — поставь 0 и настрой на слух при прослушивании.

#### Шаг 2: Запись

```
1 Latency ✓   2 Запись ←   3 Превью
────────────────────────────────────────────────────
Запись голоса   offset=86мс

Инструментал (для ориентира)
[══════════════════════════════════] ← аудиоплеер

          ⏺
         ────
         0:00            ← таймер
    Нажми для записи

████████░░░░░░░░░░░░░░░░░░░  ← уровень микрофона
Уровень: -18 dBFS
```

**Процесс записи:**
1. Нажми `⏺` — инструментал начнёт играть автоматически
2. Пой в микрофон
3. Нажми `⏹` (та же кнопка) когда закончишь
4. Файл автоматически загрузится на сервер

**Уровень микрофона:** следи за полоской. Идеально — заполнена на 60–80%. Если мигает красным (`-3 dBFS ⚠️ клиппинг!`) — убери микрофон подальше.

#### Шаг 3: Превью и скачивание

```
1 Latency ✓   2 Запись ✓   3 Превью ←
────────────────────────────────────────────────────
Превью и загрузка

│ Голос (raw)  │ [══════════════════════] │ ← твой голос без обработки
│ Микс         │ [══════════════════════] │ ← голос + инструментал

[⬇ Скачать микс]   [🔄 Новый дубль]

─ История дублей ──────────────────────────────────
│ 0:52  22.05.2025 14:35 · offset 86мс │ ready │ [⬇] [🗑] │
│ 0:48  22.05.2025 14:28 · offset 86мс │ ready │ [⬇] [🗑] │
```

**Статус микса:**
- `processing` — FFmpeg смешивает файлы (обычно 10–30 секунд)
- `ready` → появляются плеер и кнопка скачивания

| **WebVTT** | Браузерные видеоплееры, HTML5 `<track>` |
| **MIDI** | DAW (GarageBand, FL Studio), разбор мелодии |

**Восстановить версию** — если Whisper запускался несколько раз (с разными моделями), все версии сохраняются. Кнопка «Восстановить» делает выбранную версию активной без удаления других.

**Повторная обработка** — выбери модели и нажми «🔄 Запустить». Текущие данные сохранятся как предыдущая версия.

**Audit log** — раскрывающийся список всех событий: когда загружен, когда разделён, когда транскрибирован, были ли reprocess-запросы.

## 8. Полный рабочий цикл

```
1. bash start.sh          → получи публичный URL
2. Открой Colab           → вставь URL и секрет → Run all
3. Открой localhost:8000  → кликни «+ Загрузить»
4. Загрузи трек           → статус: created
5. Жди Colab              → статус: processing → ready (5–15 мин)
6. Открой плеер           → karaoke работает!
7. (опционально) Редактор LRC → правь текст → Ctrl+S
8. (опционально) Запись   → пой поверх инструментала
9. (опционально) Экспорт  → скачай SRT для видео
```

**Время обработки трека (3–4 мин):**
- Загрузка и конвертация: ~10 сек
- Ожидание Colab (poll interval): ~10 сек
- Demucs separation: 2–5 мин (T4 GPU)
- Whisper transcription: 30–90 сек (зависит от модели)
- Slicing на телефоне: 10–30 сек

## 9. Экспорт файлов

### LRC
Стандартный формат для karaoke. Открывается в:
- **Android:** Poweramp, AIMP, PocketLyrics
- **Desktop:** VLC, foobar2000 (с плагином), AIMP

### SRT
Субтитры для видео. Использование:
```
# Добавить к видео через FFmpeg
ffmpeg -i video.mp4 -i subtitles.srt -c copy -c:s mov_text output.mp4
```

### WebVTT
Для веб-плеера:
```html
<video>
  <source src="video.mp4">
  <track src="lyrics.vtt" kind="subtitles" srclang="ru" label="Текст">
</video>
```

### MIDI
Приблизительная мелодия вокала. Точность ±1–2 полутона.
- Открой в GarageBand, FL Studio, MuseScore
- Полезно для изучения мелодии или аранжировки

## 10. Повторная обработка с другой моделью

Если качество разделения или транскрипции не устраивает:

1. Открой `/projects/{id}/history`
2. Выбери модели:
   - **Demucs:** `htdemucs` → `htdemucs_ft` (лучше) → `mdx_extra` (лучшее)
   - **Whisper:** `base` → `small` → `medium` (лучше, но медленнее)
3. Нажми **«🔄 Запустить»**
4. Убедись что Colab-воркер запущен
5. Подожди — старая транскрипция сохранится как v1, новая будет v2

**Рекомендации по моделям:**

| Ситуация | Demucs | Whisper |
|----------|--------|---------|
| Начальная обработка | `htdemucs` | `base` |
| Плохое разделение | `htdemucs_ft` | — |
| Плохая транскрипция | — | `small` |
| Максимальное качество | `mdx_extra` | `medium` |
| Трек с инструментами (drum/bass/guitar) | `htdemucs_6s` | — |

## 11. Студия записи

### Советы для хорошей записи

**Оборудование:**
- Наушники обязательны (иначе микрофон запишет инструментал + эхо)
- Проводные наушники лучше беспроводных (меньше задержка)
- Расположи телефон на расстоянии 15–20 см от рта

**Процесс:**
1. Сначала прослушай трек через плеер несколько раз
2. На странице записи нажми «Измерить задержку» один раз
3. Запомни значение — оно останется для всех записей проекта
4. При первом дубле можно записать тихо — просто для проверки синхронизации
5. Прослушай микс в секции «Превью» — если голос смещён, скорректируй offset вручную

**Если голос не совпадает с музыкой:**
- Голос звучит раньше → уменьши offset на 20–30мс
- Голос звучит позже → увеличь offset на 20–30мс
- Обновить offset для конкретной записи нельзя — сделай новый дубль с исправленным значением

## 13. Частые проблемы

### «Нет связи с телефоном» в Colab

**Причина:** localtunnel не запущен или URL изменился.

**Решение:**
1. Проверь что `start.sh` всё ещё работает в Termux
2. Скопируй новый URL из вывода `start.sh`
3. Обнови `STUDIO_URL` в ячейке конфига Colab
4. Перезапусти ячейку с основным циклом

### Проект завис в `processing`

**Причина:** Colab отключился или задание зависло.

**Решение:** Через 10–15 минут scheduler автоматически пометит задание как `failed`. Можно перейти в «История / Экспорт» и нажать «🔄 Запустить».

### «FFmpeg не найден»

```bash
pkg install ffmpeg -y
```

### Ошибка при загрузке файла «413»

Превышен лимит размера. Увеличь в `.env`:
```env
MAX_FILE_SIZE_MB=500
```
И перезапусти сервер.

### Нет звука в плеере

- Браузер требует жест пользователя перед воспроизведением — нажми ▶
- Проверь что Volume не на нуле
- Попробуй другой браузер (Chrome рекомендуется)

### Плохое качество разделения

- Попробуй модель `htdemucs_ft` или `mdx_extra` (см. раздел 10)
- WAV лучше MP3 как исходник
- Моно-треки разделяются хуже стерео

### Whisper плохо распознаёт слова

- Переключись на модель `small` или `medium` (раздел 10)
- Укажи язык явно в Colab: `WHISPER_LANGUAGE = "ru"`
- Если трек на русском — base часто путается, `small` намного лучше

### Localtunnel занят (ошибка субдомена)

Скрипт автоматически попробует случайный субдомен. Если не помогло:

```bash
# Вручную с другим субдоменом
lt --port 8000 --subdomain my-studio-$(date +%s)
```

### PWA не устанавливается

- Открой сайт в Chrome через HTTPS (localtunnel URL)
- Chrome предложит установить через кнопку в адресной строке или меню «Добавить на главный экран»

## 14. Справочник по API

Для разработчиков и автоматизации.

### Загрузка трека
```
POST /api/upload
Content-Type: multipart/form-data
Body: file=<audio>
Response: { project_id, job_id, status }
```

### Статус проекта и ассеты
```
GET  /projects/{id}                    → HTML страница
GET  /api/projects/{id}/assets/{type}  → скачать файл
     type: original | vocal | instrumental
```

### Транскрипция
```
GET  /api/projects/{id}/transcription         → строки с таймингами
PATCH /api/projects/{id}/transcription/lines  → обновить строки
```

### Экспорт
```
GET /api/projects/{id}/export/lrc   → .lrc
GET /api/projects/{id}/export/srt   → .srt
GET /api/projects/{id}/export/vtt   → .vtt
GET /api/projects/{id}/export/midi  → .mid
```

### Повторная обработка
```
POST /api/projects/{id}/reprocess
Body: { "demucs_model": "htdemucs_ft", "whisper_model": "small" }
```

### Записи
```
POST   /api/projects/{id}/recordings
GET    /api/projects/{id}/recordings
GET    /api/recordings/{id}
GET    /api/recordings/{id}/mixed   → скачать микс
DELETE /api/recordings/{id}
```

### Системные
```
GET /health          → статус сервера
GET /api/metrics     → метрики
GET /api/models      → список доступных моделей
```

### WebSocket (прогресс)
```
WS /ws/projects/{id}
Events: progress | done | error
```
Пример подключения:
```javascript
const ws = new WebSocket('ws://localhost:8000/ws/projects/PROJECT_ID');
ws.onmessage = e => {
  const msg = JSON.parse(e.data);
  if (msg.event === 'progress') console.log(msg.stage, msg.percent + '%');
  if (msg.event === 'done')     location.reload();
};
```
